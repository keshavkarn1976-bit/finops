FinOps Auto-Triage Agent

Reads every pending cost line item out of a CSV file living in this GitHub repo, batches them (15 at a time) to Gemini for a fixed-taxonomy classification, files each batch as structured tickets straight into data/tickets.json — each ticket already carrying its resolver team — then commits the CSV back with those rows marked done. Repeats batch by batch until nothing is left pending.
1. PERCEIVE — read CSV from repo
→
2. DECIDE — Gemini batch-classifies (fixed categories)
→
3. ACT — file ticket batch to tickets.json
→
4. UPDATE — commit CSV batch as done
→
repeat per batch, or stop if empty
